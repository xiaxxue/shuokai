# 说开 SHUOKAI

一个结构化沟通产品的交互原型：当普通聊天陷入重复、误解或升级，帮助双方先分别表达，再共同看见事实、理解、影响、请求与真实分歧。

## 原型覆盖的流程

- 选择本次沟通目标
- 语音表达与本地录音预览
- AI 单问题澄清（模拟内容）
- 本人审核并批准观点卡
- 低压力邀请对方加入
- 双方共同视图与分歧定位
- 创建可逆、可复盘的 7 天实验
- 工程视图展示状态机事件

## 本地运行

```bash
npm install
npm run dev
```

验证：

```bash
npm run lint
npm test
```

当前版本是前端交互原型。录音保留在浏览器本机；AI 内容、邀请发送、账号、持久化和真实双人同步尚未接入。
